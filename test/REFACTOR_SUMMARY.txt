================================================================================
                              核心问题
================================================================================

【发现的问题】
代码保存的是随机噪声结构，而非去噪后的蛋白质结构

【问题表现】
- 生成结构的CA-CA距离: 27.6 Å (正常应为3.8 Å)
- TM-score: 0.08-0.09 (随机结构的典型值)
- 所有时间步TM-score完全相同

【根本原因】
1. 使用sample_ref()采样随机噪声
2. 没有实现逆向扩散的去噪过程
3. Score network输出被完全忽略
4. 直接保存输入的随机噪声

================================================================================
                              修复方案
================================================================================

【新建文件】
score_predictor_TMscore_fixed.py

【核心修复】
1. 新增 reverse_diffusion_sampling() 函数
   - 实现完整的逆向扩散采样过程
   - 从随机噪声开始，逐步去噪100次
   - 每步调用 diffuser.reverse() 更新结构

2. 关键调用链
   random_noise → model.predict_score → diffuser.reverse → updated_structure
   (重复100次)

3. 保留原有功能
   ✓ Score记录（rot_score, trans_score）
   ✓ TM-score计算
   ✓ PDB文件保存

================================================================================
                              关键要点
================================================================================

1. 扩散模型的核心是"逐步去噪"
   - 不是一次性生成
   - 需要多次迭代（通常100-1000步）

2. sample_ref() 的作用
   - 仅用于采样初始随机噪声
   - 不是最终的生成结果

3. diffuser.reverse() 是关键
   - 实现从噪声到真实结构的转换
   - 必须在循环中多次调用

4. Score network 输出 score（梯度）
   - 不是直接输出结构
   - 用于指导去噪方向
